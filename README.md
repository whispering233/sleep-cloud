# sleep-cloud

一个跑在 Cloudflare 上的线上睡眠大厅。**浏览器打开即用，不需要下载、不需要注册。**

睡不着的人可以来这里躺下、走动、看看别人，也看看那些已经睡着的人。

> **线上入口：<https://sleep-cloud.whispering233.com>**（Worker 的生产入口是一条**路由**；`workers.dev` 与 Preview URLs 已关闭。路由带的 zone 名不写进仓库，配置方式见 [`docs/design/build.md`](docs/design/build.md) §4.2。）
>
> **当前状态：v0.0.7（2026-10-21）**——这一版先让人**看懂这个厅**，再让人**有地方说话**：**说明面板「关于失眠云」**（一页产品说明 + 每次更新了什么，没读过时进厅前自动出现一次，之后在齿轮里随时翻回来；入场层标题右侧同时多了一个小字版本号——进不去厅的时候也拿得到版本）、**插槽面板的第二个内容「类型文本」**（动作行书本图标一按就是一条冷笑话，抽过的记得住、全抽干能「再看一遍」，退出与刷新都还是刚才那条；内容与阅读进度全在本地，不发任何上行）、**举报闭环**（点小人 → 私聊行「举报」→ 事由 → 确认；24 小时内同一对只占一行、证据是对方最近 ≤10 条已打码发言、留 90 天；后台 `/admin` 多一页举报列表与一张「谁被最多人举报」的折叠表，封禁仍只在台账那一处）、**聊天词库扩到约 2.5 万条**（生成产物 `npm run words`；手机号 / 邮箱 / URL / 裸域名 / 平台引流一律**打码不拦截**，昵称走更窄的词集——命中即进不来，误伤代价大得多）、**雨声从天气里拆出来了**（齿轮里两颗各管一半：天气只管画面、雨声只管声音，缺键时无雨 + 静音），别人的**名字一直浮在头顶**（床上、站着、走动都一样），**睡痕不再 12 小时后消失**（跟床位归属同寿，30 天不回来才让床），躺在床上点床号胶囊只把相机对准我的床（不再起身、不被叫醒）。

> **上一版 v0.0.6（2026-10-20）**——这一版把「一堆火、一只猫、一场雨」凑齐了：**预留位的两样装饰**（躺下时床头篝火亮起、床尾的猫跟着我走，只有自己看得见，点它演一段摸摸头）、**天气**（雨天 / 无雨一颗开关同时驱动屏幕空间的雨层与雨声，个人偏好、不进协议）、**隐私与风控**（来源台账带昵称、封禁、审计、举报与后台 `/admin`、隐私说明 `/privacy`；聊天词库约 2.5 万条），并把**构建基线钉在 Chromium 100**（夸克 / UC 的内核；Popover 等新 API 全部带降级路径）。上一版 v0.0.5 的 HUD 一条通栏、固定缩放档位、快捷用语与「点完立刻起步」都还在。逐条见 [`CHANGELOG.md`](CHANGELOG.md) 的 v0.0.6 段。

> **v0.0.5 的重头戏是「输入会话」这一整套**：打字态现在是 store 里的一等状态（`composer: idle | typing`），**焦点只是它的入口之一**——控件被卸载不发 `blur`、别的控件会抢焦点、系统手势也能吞掉焦点，把焦点当状态本体就会卡死在「面板贴在屏幕上方、回不到大厅」（旧实现点一下 😀 就再也退不出去）。现在退场只有一条路 `exitComposer()`，外加一条 `focusout` 后的对账；打字态右端常驻一枚 44px「收起」胶囊作为可见出口，`GO` 的床号输入也进同一个状态。布局改成 **CSS Grid 两态**（`auto 1fr auto` ↔ `auto auto 1fr`），面板与插槽都在流里：不再量高度、不再写位移，两态瞬切。画布在打字期间**冻结像素尺寸**（只挡「宽度不变、高度变小」——键盘的指纹），**退场后也不重算**（退场那一刻键盘还没收完，重算就是先缩再涨、两帧黑闪）。退场的可点性跟视觉同源（关闭态靠 `visibility` 退出命中——`pointer-events` 会关得太早，`inert` 又会让命中跳过整棵子树），世界层再收一道「只有画布起手的 tap 才算数」；另有一条手势纪律：**一次点按期间不许把被点的盒子拿掉**（点面板空白改成抬手才退场，否则浏览器补发的兼容鼠标事件会落到画布上，一次误点就让小人走开）。齿轮浮层改 `popover`（顶层、light-dismiss、`Esc` 全归平台）；**没有 Popover 的夸克 / UC 内核（Chromium 100）走手写开关**（点外 / `Esc` / 焦点回齿轮），兼容基线与降级约定见 [`docs/design/architecture.md`](docs/design/architecture.md) §1。逐条见 [`CHANGELOG.md`](CHANGELOG.md) 的 v0.0.6 段。
>
> v0.0.3 及更早的内容：单厅 + 床位自动伸缩（已用 75% 就提前长一档）、一间一床的厅（相邻行错位 + 每间一块预留位）、**HUD 一条通栏分三段：显示性信息（在线 / 无主空床 / 延迟）/ 可点击（床号、`GO`、看全厅）/ 设置齿轮（更换床位 + 版本号）**、**世界内 8 秒聊天气泡**（无消息列表、无历史）、**入场可选形象**、走到边缘看得见墙、无昼夜、Phaser 4 世界层。**密集屏上的字看得清了**：世界里的文字按画布 DPR 栅格化、画布按设备像素 1:1 渲染（`MAX_DPR = 3`），气泡文字升到 `label` 档（13px），床号仍是 12px。测试、类型检查、设计令牌校验均全绿。真机验收（真手指触摸 / 低端机帧率 / 低亮度观感）尚未完成，该用什么环境验证见 [`docs/design/test.md`](docs/design/test.md)。

## 它是什么

```text
打开网页 → 第一次进来先看一眼「说明面板」（点「知道了」，勾着「以后不再自动显示」）
        → 匿名入场（昵称 + 18 岁自述 + 形象，标题右边一行小字版本号）→ 看见一屏的床位和别人
        → 走到一张空床边躺下（该床从此属于我）→ 睡着 / 睡不着躺着
        → 睡不着时起身走动、看别人、聊天
        → 关掉网页 → 床上留下「睡痕」（你回来就还原；30 天不回来，床才真的让给别人）
```

- **一个大房间，一间一格**：**只有一个厅**，床位数随人来人往**自动伸缩**（117 ~ 9558，类似 `ArrayList` 扩容：不够才长，没人要了才缩）。一格 = 一条竖走道 + 一间房（一张床 + 一块留给装饰物的预留位），相邻行的床左右**错位**，所以看起来是交错排布而不是营房队列。第一次躺下即认领，30 天不出现才释放；空床很多，但「我的床位」是真实的私人物品。想换个位置？齿轮里点**「更换床位」进入换床模式**，再点一张空床就搬过去（旧床当场释放；10 秒冷却只是防止连着搬）。**平时点一张空闲床不会换床**——只给一句提示，因为一次误点的代价是丢掉旧床归属。
- **自己那一格里的两样东西**：床头的**篝火**（我躺下或睡着时烧着，起身就熄成一堆柴与石圈）与床尾的**猫**（我漫游时跟在身后 60px、躺下时回窝睡；每次打开页面它会跑过来说一句「欢迎回来」；点它一下随机演「摸摸头」或「蹭手撒娇」）。两样都**只有你自己看得见**——不进聊天、不出现在别人的画面里，也不占任何服务端资源。
- **世界只缩不放**：世界比例固定（素材 ×0.5），但相机可以**拉远到 0.175**——第 1 级厅的 117 张床正好装进手机屏宽，一眼看到厅的大致排布、以及自己在哪一片（双指捏合连续缩放；也可以从动作行那颗胶囊里挑一个**固定档**——`全厅` / `0.5×` / `0.75×` / `1×`，锁死比例、捏合只平移，档位名就写在胶囊上；**显式锁定的一档会记住**，整页重载后还在）。**上限就是 1×、没有放大**（放大必然被位图放大采样而糊）；拉远后世界文字退役，**我的人与我那张床的两颗暖点保持屏幕尺寸**。找床仍然靠**每张床上常显的床位编号**（1× 下）+ 我的床暖色标记 + 输入框上方那一行的床号。床号只编码「年龄」不编码方位，所以我的床不在视野里时那一行会给出 **8 方位箭头**，点它相机就跳回我的床；**已经在床上时点它只把相机对准我的床、零上行**（不会起身、不会被叫醒）。厅一大，走路就不够用了：同一行的 `GO` 可以**输入床号跳到任意床脚前**（瞬移 + 相机同时对准）。**版面是「上面一条字、下面一行按钮」**：顶部 HUD 只放**纯文字的显示性信息**（在线 / 还有多少床没人认领 / 延迟，一行），**可点击的两端对齐在聊天输入框上方**——左边床号 / `GO` / 缩放档位（描边胶囊），右边设置齿轮（更换床位 + 天气 + 雨声 + 关于失眠云 + 一行版本号）；展开的床号输入、换床提示与档位选项夹在按钮行与输入框之间（三者互斥）。这样 393 宽的竖屏上按钮不会把文字挤成三行。
- **天气是个人偏好**：齿轮里两颗互相独立的胶囊——**天气**（雨天 / 无雨）只管画面、**雨声**（雨声 / 静音）只管声音。想安静就切「静音」，雨照下；想只听雨不看雨也行。两个都是**缺键就是关**（第一次打开无雨、静音），切过之后就记住。它不进协议，所以同厅两个人可能一个下雨一个不下。
- **聊天只发生在世界里**：说话的人头顶浮起一个气泡（**8 秒**后消失，同一个人后来的消息覆盖前一条、最多两行），私聊只出现在两个人头上；**别人的名字一直浮在他头顶**（床上、站着、走动的都一样，点中时换成名字气泡；自己从来不画名字）；底部面板只留输入与动作——**没有消息列表、没有历史记录**。输入行右端一个 😀 键展开一排**常用 emoji**（点一下直接发出，与输入行共用同一行，所以面板不会变高）；要跟文字混排就用系统键盘打 emoji，气泡里照样显示。
- **没有昼夜**：不读时钟。明暗只跟着**我自己的行为**走——漫游 / 躺下 / 睡下 是 `0` / `0.12` / `0.22` 三档整屏减光（约 0.9 秒过渡，入场层不参与）。按时间周期变化的明暗会被读成昼夜替身，那才是被取消的东西。
- **躺下 ≠ 在线**：关掉页面后小人不会消失，而是变成更暗的**睡痕**留在床上——你回来还是躺在床上（点过「睡了」就是睡着），30 天不回来，床才真的回到可认领池。否则深夜进来的人会看到一个空荡荡的大厅。
- **断线不会把页面卡死**：手机切屏、断网之后连接会变成一条僵尸 socket（`readyState` 还是 OPEN，发出去的消息没有下文）。客户端自己管连接：三条触发点（回到前台 / 网络恢复 / 发了意图 1.5 秒没有任何回应）→ 发一条探活 `ping` → 超时就重连（1→2→4→8→15 秒退避，永不放弃）；面板顶部同时出现一条**不自动消失**的提示条与「尝试连接」按钮。**不做常驻心跳**——那会让服务端对象整夜不休眠。
- **打字时面板整体上移，世界不再闪也不乱走**：进入打字态，聊天面板与插槽面板**挪到顶部显示条下方**——顶部与键盘天然不重叠，所以界面**不读键盘高度**（这一量在部分内核里测不出来）。画布在打字期间**冻结像素尺寸**，键盘绝不可能让它重建绘制缓冲，**退场也不重算**（否则又是先缩再涨的两帧黑闪）。插槽面板铺满到屏底，快捷用语两列网格、8 条不需滚动。**出口是显式的**：右端「收起」胶囊，任何时候都点得回去。
- **读点什么**：动作行右端那颗**书本图标**（齿轮左边、只在空闲态出现）按下，底部面板换成一条**冷笑话**——纯本地的静态包（`/fun/type-texts.v1.json`，`cache-control: immutable`、文件名带版本号，换内容必须改名），不进协议、不发任何上行。右下角那颗图标抽下一条，抽过的记进 `sc.read.seen` 不再重复；全部抽干后同一位置换成「再看一遍」。**退出、刷新回来都还是刚才那条**（当前条与已读一起落盘），没读完的不会被悄悄跳过。分类取数据里的第一个——「冷笑话」只是第一个类型，以后按「类型文本」加分类，不接线、不改编排。
- **点完就动，而且不往回跳**：自己的小人不等服务端的回执——发出意图时就用**与服务端同一份寻路**算好路径，按 220px/s 外推；收到服务端位置时只许**向前**收敛，任何一次校正都不会让画面倒退（起步、中途改目标、重锚、到达同理）。代价是我看到的自己比服务端真值领先半个单程，别人眼里的我则走曾经的插值滞后——两边都写在 [`docs/design/30-movement-sync.md`](docs/design/30-movement-sync.md)。
- **睡着的人不需要位置**：他的位置就是他的床。因此大厅在没人在走动时几乎是零成本、零流量。
- **说明书就长在产品里**：**说明面板**一页讲清这个厅是什么、这一版更新了什么——内容随 bundle 走（`src/client/about.ts` 是纯数据），没有后台、也不发请求。**两个入口**：没确认过这一版公告时**进厅前自动出现一次**（记住的只是「公告版本」，正文改了才升版号，所以下一次内容更新会再出现一次）；平时从齿轮浮层里的**「关于失眠云」**随时翻回去。自动那一次底部一行「以后不再自动显示」（**默认勾选**，取消勾选 = 下次还想看），出口只有一个「知道了」（`Esc` 同一条路）——不做 ×、不点遮罩关闭，那两条都会把一次误触变成「已读」。**不存正文、不存历史**：只存一个键（`sc.about.seen` = 你确认过的那一版公告）。
- **说清记录了什么**：入场层「我已满 18 岁」那一行下面、以及齿轮浮层里，各有一个「使用须知与隐私说明」入口（`/privacy`，一个纯静态页）。六条讲清：不要求注册所以服务端从来没有你的真实身份、记录什么（访问来源 IP / 国家 / 浏览器类型哈希 / 昵称形象 / 床位）、为什么记、留多久（来源与昵称 90 天、床位 30 天、聊天不逐条存——只有举报或被举报那一刻，被举报人最近 10 条发言随那条举报存 90 天）、谁能看、以及「删除」为什么只能人工处理。**滥用防护四件**：敏感词（昵称拒绝、聊天打码，联系方式与引流也打码）、上行限流（5 条/秒）、**举报**（点小人 → 写事由 → 后台按被举报人折叠，看得到谁被最多人举报）、**封禁**（按身份或来源网络，拒绝入场；命中时给到期时间、不给原因）。运维面在同一站点的 `/admin`：单令牌、与玩家会话完全隔离，封禁动作全部留审计。
- **美术来自开源实现**：素材取自 [`WheatCloudSleep`](https://github.com/WheatBox/WheatCloudSleep)（MIT, © 2022 WheatBox），构建期做两色渐变映射后使用，见「许可」。

## 与已有产品的区别

| | 形态 | 门槛 |
| :--- | :--- | :--- |
| VR 睡眠房间（VRChat 等） | 多人躺在一起 | 需要头显 |
| 睡眠陪伴类网页产品 | 语音/文字房间 | 没有「每个人的床位」这个概念 |
| 桌面客户端开源实现（WheatCloudSleep） | 形态完全相同 | 需要下载可执行文件，且需自建服务器 |

竞品与开源参考的完整调研见 [`docs/research/competitive-analysis.md`](docs/research/competitive-analysis.md)。

## 技术选型

| 层 | 选型 |
| :--- | :--- |
| 部署 | 单个 Cloudflare Worker + 静态资源托管（同源，会话 cookie 自动随 WebSocket 握手发送） |
| 后端入口 | Hono + TypeScript（自带 HMAC 签名 cookie） |
| 房间服务 | Durable Object，**整个应用只有一个实例**，自带一份私有 SQLite |
| 前端 | React + TypeScript + Vite + Tailwind（移动端优先） |
| 世界渲染 | **Phaser 4.2.1**（独立画布，`Scale.NONE`，相机**只缩不放** `0.175 ~ 1×`；画布按 DPR ≤3 放大、**世界里的文字按同一个 DPR 栅格化**；地板是**三层程序化色块**（走道 / 房间地面 / 预留位），厅外那圈用**相机背景色**，所以推到边缘能看到「墙外的底 + 3px 墙带 + 地板」；床位与小人用**可视窗口 + 对象池**；聊天气泡程序化绘制；不用 Tilemap、不用物理引擎、不用位图字体） |
| 布局 | **共享纯函数**（`src/shared/layout.ts`）：床号 ↔ 位置、**床位区 / 地板区 / 取景范围**、可走性；**寻路与位置推进也在共享层**（`pathfinding.ts` / `movement.ts`，前端与服务端引用同一份——自身外推才能与服务端轨迹一致）。几何程序化生成，**没有场景文件** |
| 开发助手技能 | `.agents/skills/` = Phaser 4 的 28 份技能文档（项目专用，供编码助手按需读取） |

### 平台约束塑造了设计

本项目的大部分设计决定来自平台的几条规定事实：

- **单个房间服务是单线程的**，软上限约 1,000 请求/秒 → 广播必须批量合并
- **存在未完成的定时器时对象无法休眠，且持续计费** → 高频循环只能在「正在工作」期间存在
- **内存定时器不持久**（驱逐后回调不执行）→ 「必须在未来某时刻发生」的动作必须用持久唤醒
- **云端计时不精确** → 推进量按实际经过时间计算，客户端按服务端时间戳插值
- **出站 WebSocket 消息不计费**，入站消息按 20:1 折算 → 「只发变化 + 批量合并」在计费上正好最省
- **唤醒时整表读取会放大行读取计费** → 按需读单行

免费额度下的容量推演与四条硬约束见 [`docs/design/architecture.md`](docs/design/architecture.md)。

## 参与开发

先读 [`AGENTS.md`](AGENTS.md)（硬纪律与术语）与 [`docs/design/tasks.md`](docs/design/tasks.md)（当前任务卡片）。

本地运行（**干净克隆后先 `npm run tokens`**：`typecheck` 与 `test` 都依赖它的生成物）：

```bash
npm install
npm run tokens                 # 从 docs/ui/DESIGN.md 导出令牌（生成物不入库）
npm run build && npm run dev   # 完整站点（端口从 8787 起自动 +1，实际 URL 看终端）
npm run dev:web                # 前端热更新开发服务器（/api 代理到本 worktree 的后端端口）
npm test                       # 单测（L1）：纯逻辑、状态机序列穷举、布局算术
npm run typecheck
npm run art                    # （可选）从 tools/art/masters/ 的母图重新生成图集
npm run deploy                 # 部署（应急：手工；正常发版推 tag 由 CI 完成，见 docs/design/build.md §4.4）
```

设计令牌的唯一来源是 `docs/ui/DESIGN.md`（`npm run tokens` 导出为 Tailwind 主题与画布用的 JSON）：

```bash
npm run lint:design   # 基线：0 error / 0 warning
```
