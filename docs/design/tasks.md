## 卡 2｜换床模式（前端）

**范围**

- `src/client/store.ts`：新增本地状态 `switching`（默认 `false`）+ 开/关的写入口。**不是协议字段、不进快照**。
- `src/client/world/rules.ts`：`tapTargetFor` 吃 `switching`；「无主空床」分支放行 `lie` 的三种情形（我还没床 / 目标就是我那张床 / 在换床模式内）。
- `src/client/world/views.ts` + `world.ts`：模式内**无主空床**角上显示可搬标记（同一个 `marker` 几何通道，颜色换 `claimed`；只在状态翻转时重绘）；`bedLook` 之外的渲染不动。
- `src/client/components/Hud.tsx`：齿轮浮层两项（「更换床位」在上、版本号在下）；模式期间该项文案变「取消换床」；模式期间可点击组**隐藏 `GO`**；HUD 下沿（与 `GO` 输入行同一位置）显示换床提示行「点一张空床搬过去」+「取消」；进模式时若 `GO` 的输入行开着则收起。
- `world.ts` 的 `follow`：模式内**不跟随**（点自己回中仍然可用）。
- 退出路径：点地面（走过去）/ 提示行取消 / 齿轮浮层 / **在模式内点空床并发 `lie` 后立即退出** / 刷新断线（本地状态自然消失）。**起身与说话不退出**。

**不做**

- 不加超时自动退出（要挂内存定时器，见硬纪律 6）。
- 不改协议、不改服务端、不改错误码。
- 模式外点无主空床仍然是现状（换床）——**本卡是中间态，不单独部署**（收口在卡 3）。

**验收**

1. 手机视口（393×852，DPR 3）下：齿轮浮层有两项，「更换床位」是 44px 触摸目标、描边胶囊外观，版本号是纯文字。
2. 进模式后：HUD 下沿常驻提示行 +「取消」；`GO` 消失；无主空床角上出现可搬标记，**我的床仍是暖色标记**（两者同屏可辨）。
3. 模式内拖着看厅时相机**不**跟着我走；点自己仍然回中。
4. 模式内点一张无主空床 → 真的换床（自己走过去躺下、旧床暖标记消失、新床暖标记出现），且模式已退出。
5. 退出路径逐条：提示行「取消」、齿轮浮层「取消换床」、点地面（模式退出且小人走过去）。
6. 起身（在床上起身）与发一条聊天**不**退出模式。
7. 模式外点无主空床：与改动前完全一致（仍然换床、`3008` 冷却提示照旧）。

## 卡 3｜误点拦截（前端，收口）

**范围**

- `src/client/world/rules.ts`：`tapTargetFor` 的「无主空床」分支加最后一档 —— 我有别的床且**不在**模式内 → 返回 `{ kind: 'notice' }`（新 kind，不带文案）。
- `src/client/world/world.ts`：`case 'notice'` → `showNotice('已经有一张床 · 换床在设置里')`。
- `src/client/world/tests/rules.test.ts`：四分支矩阵（我还没床 / 目标是我那张床 / 我有别的床+非模式 / 我有别的床+模式内）。
- `CHANGELOG.md`：补一条行为变更（不写任务卡语义）。

**不做**

- 不做提示去抖（现在「新提示替换旧提示、动画从头播」是既有行为，连点两次相同的服务端提示今天也是这个表现）。
- 服务端不加闸、不加错误码（见 `../api/20-api-ws.md` §4.5）。

**验收**

1. 我还没床时点无主空床 → 直接躺下认领（不加门槛）。
2. 我有床、不在模式内，点一张无主空床 → **不发送 `lie`**（网络面板无上行），出现提示「已经有一张床 · 换床在设置里」。
3. 我有床、不在模式内，点**我自己的**床（不在床上）→ 走回去躺下，**不**出提示。
4. 我有别的床、**在模式内**点无主空床 → 照常换床。
5. 在床上点自己正躺着的那张床 → 静默（`3004` 行为不变）。
6. 卡 2 与卡 3 **一起部署**（只上卡 3 = 换不了床）。
