## [ ] 卡 9：厅的边界（地板与墙）按「下一级」绘制

**目标**：让**最外圈的床四周都有走道**。现状：床位区的最右列与最上排正好贴着边界（0px），最外侧是墙、玩家绕不过去。

**改动范围**

- `src/shared/layout.ts`：
  - 新增 `wallRegionOf(index)`：**下一级的区域**（最后一档用**理论下一档 64×207 = 16307×9984**；**级表不新增可玩档**，也不补床位）
  - `isWalkable(x, y, bedCount?)` 的边界从「本级床位区」改成 **`wallRegionOf`** → 降级后旧外圈落回地板区，成为**可走的余量**（不再是厅外）
  - 单测：`wallRegionOf` 逐档等于下一级、末级等于理论下一档；**不变式 5**（`col = C−1` 的右侧、`row = 0` 的上侧都至少有一条走道宽的可走余量）；街网连通在更大的地板区上仍成立；降级后旧外圈内仍可走
- 世界层（`world.ts` 的 `rebuildRegion` 与相机夹取）：地板矩形与墙的描边按 `wallRegionOf`，相机夹取也按它

**必须遵守**：不改床位编号与位置（`cellOf` / `positionOf` / `frontPointOf` 一律不动）；不改协议；墙仍只画一条等宽线

**验收**

- `npm test`、`npm run typecheck`、`npm run build` 通过（`layout` 的单测逐条覆盖上面五项）
- `ui-verifier` 像素复核：最右列的床与墙之间**存在一条走道**（≥ 一条走道宽的像素带）、走得到墙边；最上排的床之上同理

**依赖**：卡 8 之后。
