- [ ] 卡 5：HUD 方位字形 + 可点跳过去（床号感知不到方位时的替代）
  - **背景**：床号 = 建成顺序（只编码「年龄」，不编码方位）；没有缩放，床号是世界里唯一的导航线索。新格距下厅变大（第 1 级 2249×1404、末档 20414×12636），「我的床在哪边」必须直接告诉用户。
  - **改**：HUD 那条「床号 37」在**我的床不在可用视口内**时补一个 8 方位字形（`↖↑↗→↘↓↙←`）；在视野内不显示（世界里的暖标记已经够了）。**整条可点** = 相机对准我的床（新增 `WorldHandle.focusMyBed()`），与既有的「点自己 = 回中」配成一对。**编号规则不改**（「外圈改蛇形编号」已进 backlog）。
  - **实现约束**：方位在**世界层每帧**算（它本来就有 `viewRect()` 与我的床坐标），**只在字形变化时**写 store —— 不把逐帧计算搬进 React 渲染循环；视野内 / 外按**可用视口**判（扣掉顶部 HUD 与底部聊天面板），否则「床在面板后面」会被误判成视野内。纯函数 `bedDirection(viewRect, point)` 放 `src/client/world/rules.ts`。
  - **验收**：单测覆盖 `bedDirection`（8 个方位 + 视野内返回 `undefined`）；`ui-verifier` 用**手机视口 393×852** 实测：拖动使我的床离屏 → 出现字形 → 点它相机跳到我的床；床回到视野内 → 字形消失。
