## 卡 1 · 动作行右端的说法跟上「礼物 + 齿轮」

`docs/design/60-interaction-shell.md` §9「已知代价」第一条还写着 typing 态「**连同它左边那四颗**」，与同一份文档 §4 的「右端那一组两颗（礼物 / 齿轮）」、`docs/ui/DESIGN.md` 的 `action-row` 行、`src/client/components/ActionRow.tsx:320` 都相反——v0.0.9 起留言板 / 求签 / 游戏 / 随机阅读已搬进礼物托盘，动作行右端只剩礼物与齿轮两颗。

只改那一句：把「四颗」改成「两颗（礼物 / 齿轮）」，示例列表（换床 / 缩放 / 看版本）不动——三者确实都还在齿轮浮层里。

**验收**：`grep -n "四颗" docs/design/60-interaction-shell.md` 无输出。`docs/ui/DESIGN.md` 与 `backlog.md` 里那两处「四颗」是对的（分别指托盘内四项、按下态实测的按钮数），一律不动。
