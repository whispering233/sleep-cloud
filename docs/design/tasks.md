### 卡 1：内容指纹改成「按行」归一化（换行算内容）

**为什么**：`aboutToken` 先 `replace(/\s+/g, ' ')`，把换行也折成空格；而这个格式里「行就是块」（`## ` / `- ` / 段落全由行决定）。于是「把一段拆成两行 / 把两行并成一行」这种**渲染结果变了**的改动不会让指纹变 → 用户看不至这一版。设计见 `docs/design/90-about-panel.md` §3.1。

**改什么**（只两处）
1. `src/client/about.ts` 的 `aboutToken`：归一化换成按行——`raw.split('\n').map((line) => line.replace(/\s+/g, ' ').trim()).filter((line) => line !== '').join('\n')`。注释同步成：折行内空白、去行首尾、丢空行、**保留换行**（换行是结构）；口径一变全体会与内容更新一起再弹一次。
2. `src/client/tests/about.test.ts` 的「内容指纹」两条断言：
   - **必须改**：`aboutToken('第一段\n\n第二段\n')` 与 `aboutToken('  第一段  第二段  ')` 在新口径下**不再相等**（前者两段、后者一段）。改成断言「空行与行内 / 行尾空白不影响」：`aboutToken('a\n\nb\n')` === `aboutToken('  a  \n b ')`。
   - `aboutToken('a\r\nb\r\n')` 的对照组从 `'a b'` 换成 `'a\nb\n'`（CRLF 与 LF 等价，这条要留）。
   - **新增**：「换行切分变 → 指纹变」：`aboutToken('一\n二')` !== `aboutToken('一 二')`。

**不要碰**：`PREFS_VERSION`（碰了会多弹一次）、`sc.about.seen` 的键与形状、FNV-1a 本体、`about.json` 的内容（那是卡 2）。

**验收**：`npm test`；`npm run typecheck`。

**改什么**：`src/client/about.json` 里 `## 最近更新` 后面的四条**整段替换**成三条（逐字照抄 `docs/design/90-about-panel.md` §4.1 当前文案）：

**不要碰**：其它三节、`text` 以外的字段、`about.ts`、任何代码。

**验收**：`npm test`（`about.json` 合规单测：正文非空、≤ 24 块、至少一个小节）。
