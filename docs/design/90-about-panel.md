# 说明面板（about panel）

**一句话**：一页纯文档——这个厅是什么、这一版更新了什么。它只在「没确认过这一版公告」时挡在大厅前面一次，之后从齿轮浮层随时能翻回去。

## 1. 什么时候出现

| 触发 | 条件 | 出口 |
| :--- | :--- | :--- |
| **自动**（首访 / 新公告） | `sc.about.seen` 缺键，或它的值与 `ANNOUNCE.version` 不相等 | 主按钮「知道了」（`Esc` 同路）+ 勾选框 |
| **手动**（齿轮浮层 →「关于失眠云」） | 随时（打字态齿轮不可达，见 `60-interaction-shell.md` §9） | 主按钮「知道了」（`Esc` 同路），**无勾选框** |

**页面态顺序**：`加载 → 说明面板（若需要）→ 入场层 → 大厅`。

面板渲染在入场层**之前**（`aboutOpen` 优先于入场层）。理由是层级而不是顺序偏好：入场层是**不透明满屏底**（`outside`）且盖住画布，任何浮在它上面的东西都要另写一套层级；而「先知道这是哪、再填昵称」也符合读者的顺序。代价是首访者要读两屏才进厅——接受，因为这一屏一生只自动出现一次。

## 2. 已读语义（ack）

- **只有一个出口**：主按钮「知道了」（`Esc` 走同一条路）。点它 = 关闭，并按**那一刻的勾选状态**决定是否落盘。
- 勾选框「**以后不再自动显示**」**默认勾选**，只出现在**自动打开**的那一次：
  - 勾着关 → 写 `sc.about.seen = ANNOUNCE.version`；
  - **取消勾选**再关 → **不写**（意思是「下次还想看」），下次进厅照旧弹。
- **不做第二个出口**：没有右上角 ×、不点遮罩关闭、不放一颗中性的「关闭」。这套语义的前提就是「按了按钮 = 我确认过了」，而第二颗按钮要么承诺它做不到的事（中性关闭却不记录），要么悄悄记录用户没答应的事。同理**不做点遮罩关闭**：遮罩上的每一次误触都等于「已读」。
- 勾选框**只在自动路径出现**：从齿轮打开本来不记录任何东西，「你不读也会被记住」在这里不成立。

## 3. 键与判定

| 键 | 值 | 缺键 | 判废 |
| :--- | :--- | :--- | :--- |
| `sc.about.seen` | `{"v":1,"seen":"0.0.7"}` | 等于「从未确认过任何公告」（首访，或本功能上线后的第一次） | `seen` 不是非空字符串、或超过 32 字符 → 删该键 + 当缺键 |

判定是一个纯函数：

```text
shouldShowAbout(seen: string | undefined) → seen !== ANNOUNCE.version
```

**不校验 `seen` 是不是合法版本号**：它只被拿去与 `ANNOUNCE.version` 逐字比较，坏值唯一的后果是**再弹一次**（无副作用）。键协议与读写规则见 `40-client-storage.md` §2。

### 3.1 本功能上线那一刻，全体都算「没确认过」

需求说的是「第一次进入大厅」。代码里没有「第一次」这个事实，只有**缺键**——而本功能上线时所有已有设备的 `sc.about.seen` 都缺键，与真首访**不可区分**。

**所以不做种子重置、不碰 `PREFS_VERSION`**：老用户多读一次产品介绍，代价很小（对他而言，这一版的产品介绍本来就是新的）。任何「我是不是老设备」的推断都是在用另一个缺省去猜缺省（例如「有 `sc.weather.rain` 却没有 `sc.about.seen`」——那也是推断，而且会随初始化时机漂移）。

**已知代价**：`PREFS_VERSION` 递增（任何键的形状变化都会让它递增）会让所有键判废 → 说明面板**再弹一次**。接受：一版一重置本来就是「偏好回默认」的文档化行为，而说明面板再弹一次本身无害。

## 4. 内容

内容住在 `src/client/about.ts`（纯数据 + 上面那个纯函数，DOM-free，可单测）：

```text
ANNOUNCE = { version, intro, sections: [{ title, items: string[] }] }
```

- **`ANNOUNCE.version` 与 `package.json` 的 `version` 不是同一个数**：前者是**公告版本**（只有内容真的变了才升），后者是发布版本（补丁发布不一定改内容）。齿轮浮层里显示的仍是 `APP_VERSION`（排查用），面板里显示的是公告版本——两者不互相推导。
- **只列最近一版**：面板是通知，不是历史；更早的更新去 GitHub Releases。
- **首访者与老用户看同一份内容**（介绍在前、更新在后）：不做「两种内容形态」，少一套分支。
- 条目上限 **6 条 / 节**（单测守着）：超了说明该拆成文档，而不是让面板变成长篇。
- 单测还守：`version` 形如 `x.y.z`、`intro` 非空、每节的 `title` 与 `items` 非空。

**改内容的手续**：① 改 `about.ts` 里的字 ②**内容真的变了**才升 `ANNOUNCE.version`（升了 = 所有设备下次进厅会看到）。发版清单里跟着走（`build.md` §4.3）。

### 4.1 首版文案（内容的所有权在作者，改字不需要改代码）

```text
标题：失眠云              ← 与入场层标题同一颗（不加公告版本号）
intro：浏览器打开就是一个睡眠大厅：每个人有一张属于自己的床，躺下时小人睡在床上，
       睡不着的人可以在厅里走动、看见别人、说句话。

节：这是什么
  · 只有一个厅，床位随人来人往在 117 ~ 9558 之间伸缩，你的床永远不动
  · 第一次躺下就认领那张床，别人不能睡；30 天不回来才会释放
  · 睡不着就起身：点地面走过去、点小人看名字、点床号跳过去看
  · 说话只在大厅里：头顶一个气泡停 8 秒，不保存、不留历史

节：最近更新 v0.0.7
  · 新增「关于失眠云」：产品说明与每次更新的内容都在这一页
  · 首次进入大厅前会自动显示一次，读一次就够
```

（这一版的两条更新都在说面板自己——接受：它是这次发布唯一的新东西，而且这一节从下一版起就有真实内容。）

## 5. 渲染与层级

- **世界走画布，界面走 DOM**（硬纪律 16）：这是文档面板，全部是 DOM。
- **复用入场层那套壳**：`.entry-overlay`（不透明底 `outside` + 安全区内边距 + 自己可滚）+ `.entry-card` + `.entry-title` + `.action-primary`；新增的只有正文段落与小节列表两三个类。同一屏、同一批用户、同一套排版，再造第二套只会让两屏不一致。
- **不进 `.app-shell` 的网格**：它不是常驻面板，是**覆盖整屏的临时层**（`position: fixed; inset: 0`），因此不参与 Grid 两态、不做相机坐标补偿（`60-interaction-shell.md` §3）。
- **层级**：世界层与聊天面板之上、`tone-layer` 之下——三档减光照旧整屏连续（连它一起减光），与世界同向。
- **打开前先退打字态**：齿轮里的入口只在空闲态可达，但打开前仍统一走 `exitComposer()`（`60-interaction-shell.md` §2 的出口唯一），避免以后多一个入口时各自为政。
- **焦点给「知道了」，但不许它把面板滚到底**：`.entry-overlay` 自己可滚，而默认的聚焦会把目标滚进视野——内容一长，面板就直接从最下面打开、标题与介绍全在顶上被跳过。所以**聚焦必须带 `preventScroll`**（`focus({ preventScroll: true })`），面板永远从第一行开始展示。这不是美观问题：它是「长内容能不能读」的前提。
- **没有画布**：不进 Phaser、不开相机、不发上行。服务端不知道它存在。

## 6. 不做（与理由）

| 不做 | 理由 |
| :--- | :--- |
| 「历史版本」列表 / 公告中心 | 没有需求方；GitHub Releases 就是历史 |
| 「有未读更新」角标 / 红点 | 它要求记住「上次看到哪一版」并在每次进厅比对，还会把「点掉红点」变成任务。面板一生只自动出现一次，不需要第二套未读语义 |
| 服务端下发公告内容 | 那要新增接口、缓存与审核语义，而公告本来就是随版本发布的一份代码。内容源在 bundle 里 |
| 多标签页 / 跨设备同步 | 与全部其它偏好同一个立场（`40-client-storage.md` §4） |
| 点遮罩 / × 关闭 | 见 §2：单一出口是这套已读语义的前提 |

## 7. 验收

| 层 | 判据 |
| :--- | :--- |
| **L1**（vitest） | `shouldShowAbout`：缺键 → true；同版本 → false；旧版本 → true；判废后的坏值 → true。`ANNOUNCE` 的形状（§4） |
| **手工**（桌面浏览器 + 手机视口 / 模拟器） | 干净存储首访：面板出现 → 点「知道了」→ 入场层出现；重载：不再出现；**取消勾选**再关 → 重载仍出现；齿轮 →「关于失眠云」→ 面板出现 → 关闭后大厅仍在 |
| **L3**（模拟器） | 竖屏：卡片不溢出、内部可滚、勾选框整行 44px、`Esc` 与按钮同路、三档减光压住面板 |

## 8. 术语

| 用 | 不用 | 说明 |
| :--- | :--- | :--- |
| 说明面板（about panel） | 公告框、弹窗、欢迎页 | 它是一页文档，入口两个、出口一个 |
| 公告版本（`ANNOUNCE.version`） | 版本号、app 版本 | 说明面板内容的版本，形如 `0.0.7`。与发布版本（`package.json`）不是同一个数 |
| 已读（ack） | 看完、记录阅读 | 把公告版本写进 `sc.about.seen`。它表达「这一版我见过了」，不是「我读完了」 |
