# 错误码

## 1. 约定

| 项 | 约定 |
| :--- | :--- |
| 编码 | 字符串数字，成功为 `"0"` |
| 分段 | **1xxx 会话与入场** / **2xxx 大厅与房间** / **3xxx 床位** / **4xxx 内容与限流** / **5xxx 风控（第一版仅预留）** / **9xxx 系统** |
| 呈现 | `msg` 面向开发者；面向用户的文案由前端按 `code` 映射，不复用 `msg` |
| 预留段 | **5xxx 段第一版不返回任何码，但必须存在于枚举中**，避免第二版改协议 |
| 已删除的码 | `1006`（时区校验）随厅时区概念一起删除；`3007`（已经有一张床了）随「换床开放」删除。**编号不重用**，留空洞以免旧日志与新语义撞车 |

## 2. 错误码表

| code | msg | 说明 | 用户可见文案方向 |
| :--- | :--- | :--- | :--- |
| "0" | "success" | 成功 | — |
| "1001" | "invalid session" | 会话 cookie 缺失或验签失败 | 静默重新签发会话，不打扰用户 |
| "1002" | "age confirmation required" | 未完成 18 岁自述确认 | 「进入前请先确认」 |
| "1003" | "nickname required" | 尚未设置昵称 | 「给自己起个名字吧」 |
| "1004" | "nickname too long" | 昵称长度不在 1~16 之间（含去空白后为空） | 「名字 1~16 个字」 |
| "1005" | "nickname contains blocked words" | 昵称命中敏感词 | 「这个名字不能用，换一个」 |
| "2001" | "hall not found" | 厅标识不匹配（只应出现在部署版本错配时） | 「请刷新页面」 |
| "2002" | "hall is full" | **级表触顶**：最后一档（9558 张床）全部有主或有占用，无法再扩 | 「这个大厅满了」 |
| "2003" | "layout mismatch" | **布局版本不一致**（几何是程序化生成的，用版本号代替原来的场景标识） | 「资源已更新，请刷新页面」 |
| "2004" | "handshake required" | 未完成首条握手消息就开始发业务消息 | 静默断开 |
| "2005" | "not in room" | 目标用户不在厅内（私聊等场景） | 静默丢弃 |
| "3001" | "bed out of range" | 床号越界：≥ 当前 `bedCount`，或不是整数/负数。**用户手输床号的地方（`hop` 跳转）由客户端先按 `bedCount` 拦一道并给可见提示**，所以这条对可点击界面来说是兵底 | 静默丢弃 |
| "3002" | "bed occupied" | 该床已被占用（有人或**未过期的**睡痕） | 「这张床有人了」 |
| "3003" | "bed belongs to someone else" | 该床有主且归属**未过期**（过期归属视为可认领） | 「这是别人的床」 |
| "3004" | "already in bed" | 已在床上，且点的**就是自己正躺着的那张床**（点别的床会自动起身过去，见 `20-api-ws.md` §3 的 `lie`） | 静默丢弃 |
| "3005" | "not in bed" | 不在床上，无法执行起床 | 静默丢弃 |
| "3006" | "target not walkable" | 目标点不在街网上（走道带与竖向走道之外，或落在床的占用矩形里） | 静默丢弃（客户端点到了床上或墙外） |
| "3008" | "bed switch cooling down" | 距**上次认领（含换床）**不足 10 秒，而目标是另一张尚无主的床——冷却由 `claimed_at` 读取时推导（见 `../design/config.md` §2） | 「刚换过床，稍等一下」 |
| "4001" | "message too long" | 聊天消息超长 | 「消息太长了」 |
| "4002" | "rate limited" | 上行超过 5 条/秒 | 静默丢弃（不提示，避免错误反馈本身成为放大器） |
| "4003" | "empty message" | 空消息 | 静默丢弃 |
| "5001" | "muted" | **预留**：用户被禁言 | 「你暂时不能发言」 |
| "5002" | "blocked" | **预留**：用户被封禁 | 「你暂时无法进入」 |
| "5003" | "reported" | **预留**：举报已记录 | 「已收到你的反馈」 |
| "9001" | "internal error" | 服务端内部错误 | 「出了点问题，稍后再试」 |
| "9002" | "hall unavailable" | 房间服务暂时不可用（部署中/超额） | 「大厅暂时进不去，稍后再试」 |

## 3. 使用规则

| 规则 | 说明 |
| :--- | :--- |
| HTTP 接口 | 通过响应体 `code` 返回，HTTP 状态码保持 200 |
| WebSocket | 通过下行 `error` 消息返回，不关闭连接（除 `2003` / `2004` 需要断开） |
| 静默类错误 | `3001` / `3004` / `3005` / `3006` / `4002` / `4003` / `2005` 不弹提示，避免把错误反馈本身变成放大器 |
| 可恢复类错误 | `3002` / `3003` / `3008` / `1004` / `1005` / `4001` 必须给出可见反馈，用户能立刻改正 |
| 会话类错误 | `1001` 静默处理，用户不该感知到会话机制 |
| **厅满** | `2002` 是唯一会给用户看「厅满了」的错误。它在**入场前**由 HTTP 判定（`/api/me`），因为厅满时不该让人建连再被踢 |

## 4. 与旧版的差异

| 变化 | 原因 |
| :--- | :--- |
| 删 `1006` | 厅时区概念已删除（见 `../design/config.md` §2） |
| `2002` 语义从「厅容量 256 被认证完」变成「级表触顶 9558 被认领完」 | 床位数改为自动伸缩 |
| `2003` 文案从「场景不一致」变成「布局版本不一致」 | 几何改为程序化生成，没有场景文件了 |
| `3001` / `3002` / `3003` 的判据加「过期」前缀 | 睡痕过期与归属过期改为**读取时推导**（见 `../db/schema.md` §6） |
| `3006` 的判据从「场景格不可走」变成「不在街网上」 | 走道模型从整片地板改成规则街网 |
| 新增 `3008` | 换床有了 10 秒冷却：冷却期内在另一张无主床上躺下 → 可见提示（用户等几秒即可，属可恢复） |
| 删 `3007` | 换床已开放（旧床当场释放）——「你已经有一张床了」不是服务端会返回的错误。**编号不重用**，留空洞；客户端拦下的那一下用的是本地提示（「已经有一张床 · 换床在设置里」），不是错误码 |
